# Ressources par Défi

## Défi 1 : Agent LLM (Planner-Executor)

### LLM Gratuits & APIs
- **Google Gemini** : [aistudio.google.com](https://aistudio.google.com) - API gratuite, pas de limite d'usage
- **Ollama** (local) : [ollama.ai](https://ollama.ai) - Llama 2, Mistral, Zephyr (zéro coût, GPU recommandé)
- **Hugging Face Inference** : [huggingface.co/inference-api](https://huggingface.co/inference-api) - Gratuit avec limites
- **Groq** : [groq.com](https://groq.com) - API gratuite, très rapide
- **Together AI** : [together.ai](https://together.ai) - Crédits gratuits pour essayer

### Frameworks pour Agents
- **LangChain** : Framework complet pour agents ReAct - [python.langchain.com](https://python.langchain.com)
- **LlamaIndex** : Gestion mémoire & indexation - [llamaindex.ai](https://llamaindex.ai)
- **AutoGen** : Framework multi-agents Microsoft - [microsoft.github.io/autogen](https://microsoft.github.io/autogen)
- **Pydantic AI** : Framework léger pour agents - [ai.pydantic.dev](https://ai.pydantic.dev)


### Outils & Librairies
- **Python-dotenv** : Gestion des clés API
- **Requests** : Appels HTTP pour outils externes
- **JSON** : Parsing des réponses structurées
- **SQLite** : Stockage mémoire épisotique simple

### Ressources & Tutoriels
- LangChain Agents Documentation : [python.langchain.com/agents](https://python.langchain.com/agents)
- ReAct Paper & Implémentations : [paperswithcode.com](https://paperswithcode.com)

- Examples d'agents Open Source : Recherchez "React agent Python" sur GitHub

### Outils Externes Gratuits pour Vos Agents

- **Calculator API** : Intégrée dans LangChain
- **Wikipedia API** : pywikipedia - Recherche d'information
- **OpenWeather** : [openweathermap.org](https://openweathermap.org) - API météo gratuite
- **News API** : [newsapi.org](https://newsapi.org) - Gratuit pour développeurs
- **REST Countries** : Données pays sans authentification
